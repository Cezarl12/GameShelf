# Wireframe-uri GameShelf (SCRUM-123)

Wireframe-urile aplicației web **GameShelf** (versiuni **Desktop** și **Mobile**), realizate conform identității vizuale stabilite în [`docs/design/design-system.md`](../design-system.md) și [`docs/design/logo.svg`](../logo.svg):

- **Fonturi:** `Space Grotesk` (titluri) și `Inter` (text curent / UI)
- **Paletă de culori:** Primary `#4F46E5`, Secondary `#1E293B`, Background `#F8FAFC`, Card `#FFFFFF`, Text `#0F172A`, Accent `#10B981`
- **Proiecte sursă (Google Stitch):**
  - Desktop: https://stitch.google.com/projects/10008459719245822127
  - Mobile: https://stitch.google.com/projects/8701214350370018664
